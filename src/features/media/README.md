# 媒体与 AI 图片工具

MediaAsset 是图片身份及持久文件生命周期的唯一 owner。业务记录保存媒体 ID，文件放在应用内部 `persistent-media/catalog/`，引用、共享去重、备份和回收沿用同一 catalog。

## AI 图片链路

下载后可将返回的 `mediaAssetId` 交给 Chat 的 `send_image`，作为当前会话中的真实图片消息发送；下载本身不会创建聊天消息。图片消息直接引用同一素材，发送事实与预览由 Chat 的回合提交负责。

`download_image` → 现有公共 HTTPS/DNS/重定向边界 → 原生应用缓存暂存 → 文件容器与解码验证 → 事务外准备 backing → 同一事务提交 MediaAsset 与 `ai_downloaded_images` 业务引用 → 清理暂存 → 返回媒体 ID。

下载的图片不写入 MediaStore，也不会出现在系统相册或公共下载目录。下载记录属于角色，随角色删除撤销；媒体回收继续检查头像、各收藏库和历史消息等全部引用。删除收藏只撤销收藏引用，同一图片仍被下载记录或消息使用时保留文件。备份枚举下载引用，恢复出厂沿用全库与私有媒体根目录清理。

下载时可用 `file_name` 取便于检索的名字。`query_downloaded_images` 只查询当前角色自己的下载记录：`media_asset_id` 精确查询最多返回一张，或用 `keyword` 对保存的文件名做包含匹配（不进行图片语义搜索），两者选一；没有日期筛选参数。关键词结果按下载时间从新到旧，每页默认 20、最多 50 张，通过 `offset` 和返回的 `nextOffset` 翻页。同一媒体 ID 的重复下载合并为最新匹配记录，返回媒体 ID、文件名、来源 URL 和下载时间，不读取图片内容。模型使用 `view_image` 确认内容，再复用 ID；历史离开上下文窗口或被摘要压缩后仍可查询既有下载。暂不提供用户素材管理页面或相册导出入口。

`view_image` 支持媒体 ID、用户头像、自己头像和以 ID/名称指定的其他 AI 头像；重名返回候选，ID 优先。默认头像使用实际打包资源。应用设置工具的 `get_group_avatar` 复用同一视觉读取入口，由 Chat 查询群头像并裁决成员可见范围，默认群头像读取实际打包资源。群成员回复可用已授权的下载、看图与自主换头像工具；副作用提交由 Host 调用群任务持久资格检查，终止后不能继续提交下载引用或头像修改。

Host 注入头像查询和当前角色的视觉路由；配置辅助视觉时返回视觉转述，否则通过 Agent 的工具附图契约把实际图片送到下一轮主模型。工具附图在完整 tool_calls 结果批次之后组装为模型观察输入，不产生用户 Chat 消息。GIF、WebP 与动态图片转为 PNG 单帧，并明确报告单帧限制；已绑定视觉模型失效或失败时返回明确错误，不绕过角色选择。

聊天图片的当轮说明、读取失败提示及历史原文投影均保留 `mediaAssetId`，模型可直接用于看图、换头像或 `add_own_sticker` 收藏。历史投影只列文件名与媒体身份，不读取图片，不改变会话列表预览；只有旧 URI 的附件不伪造媒体 ID。已经压缩成摘要的正文由模型生成，不保证保留每张历史图片的引用。

聊天视觉读取在文件边界校验真实容器、解码与单边 8192 像素限制，再准备静态帧；不使用相册提供的 MIME 猜测实际输入。超限长截图保留原文件和媒体 ID，本轮以明确的失败原因进入文字输入，并提示用户分段或缩小后重发，不把不可用原图反复传给接口。

聊天主模型的 HTTP 400 / 422 明确图片拒绝允许一次文字降级，去掉图片与「原图已提供」标记，保留图片说明和媒体 ID，要求模型明确没有看到原图；正常文字回复沿原 T3 提交推进回复游标。流式的 fetch 与 Android XHR 共用这一请求边界，不为认证、权限、配额或服务错误去图重试。`view_image` 的工具附图和辅助视觉请求禁用这一降级，保持真实视觉交付契约。

图片不存在、文件被移除、格式损坏返回工具错误说明。头像、背景与封面获取复用同一视觉链路；应用设置的图片准备通过 `commitCroppedImageSelection` 在事务外裁剪，再由业务 owner 同事务检查权限、执行资格和 CAS 并提交引用。原图不改写，裁剪暂存由入口清理，默认绘制背景不伪造图片。

`applicationSettings` 工具包允许各 AI 修改自己、当前主理 AI 管理其他 AI 和全局图片，取代原来仅换自身头像的工具。权限、默认读取和引用契约见[应用设置工具](../../../docs/application-settings-tools.md)。

## 出口与验证

- `@features/media`：媒体 command/query、稳定 DTO、Agent 图片工具与预期图片错误。
- `@features/media/composition`：仅供 Host 组装具体 catalog/backing/repository 及图片工具端口。
- `npm run verify:ai-image-tools`：归属、迁移、取消、视觉附图及引用行为。
- `npm run verify:web-tools-native`：原生私有下载与公共联网边界单测，不生成完整 APK。

实际相册不可见性、默认头像读取与模型视觉输入仍需 Android 设备验收。

图片拒绝回归覆盖真实 BaseAIClient 的 complete、fetch stream、Android XHR stream，以及有 / 无工具、严格看图、认证 / 权限 / 服务错误与降级再次失败；尺寸检查覆盖 1080×20000 的长截图。辅助模型与图片工具专项验证已通过；真实视觉效果和原生设备行为仍需实际服务与设备验收。
