# 个人资料

「我 → 个人」进入 Expo Router 的个人资料页，展示头像、用户名、性别、年龄、身份、地区、其他与签名。列表不使用右侧箭头；点击整行进入对应字段编辑页。头像和用户名只在个人资料中修改，「我」的顶部资料只展示。

文字编辑沿用 shared/ui 的 AutoSaveDraftEditor：停止输入 1 秒后保存，失焦提交，返回前排空待提交内容。Host 导航装配通过 usePreventRemove 承接 Android 返回键与系统返回手势；无效输入或写入失败保留草稿，可修正或恢复已保存值，不使用保存按钮。用户名不能为空且最多 20 字；年龄允许留空，填写时只能是可安全表示的非负整数；性别及其余设定自由填写。

Profile 是唯一资料 owner，SQLite adapter 只提交本次变更字段，事务提交后广播资料更新，头像仍由既有媒体草稿与引用事务提交。新增字段保存在 user_profile，启动迁移保留旧姓名、头像与封面；数据库快照备份自然包含这些资料。

Host 的对话者身份提示词块聚合所有已填写的文字资料，不复制人设到另一张表，也不自动截断其他设定。头像供界面展示，不把本机图片 URI 当成文字提示词发送。群聊继续使用参与者目录中的用户名快照。

验证：`node --no-warnings scripts/verify-user-profile-persona.mjs`；原生相册、键盘和返回手势需真机验收，不构建 APK。
