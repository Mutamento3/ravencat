# 联网工具包

## Kimi 官方工具

提示词中心另列「Kimi 官方工具」包，包含 `kimi_web_search`（官方 Basic 搜索）、`kimi_web_fetch`（官方网页抓取）与 `kimi_mew`（猫叫与祝福），默认禁用、未设特批。沿用普通工具的逐 AI 权限、全局默认、拆包与星标；不会替换用户配置的普通搜索来源。搜索返回标题、链接、站点、日期和摘要；网页正文最多提供 20000 字符，并返回截断标记及原始字符数。

仅当前 AI 使用 `https://api.moonshot.cn` 或 `https://api.moonshot.ai` 的根地址／`/v1` 时可用。第三方模型渠道、代理路径、HTTP、自定义端口、含认证信息或查询参数的地址均不启用。非官方接口仍能查看工具说明，但开关和星标灰显并说明原因；既有偏好保留，换回官方接口后恢复。全局默认只对支持的接口生效，识别到官方地址不会自动授予权限。

Host 在正常授权解析时裁决接口可用性，再把同一 allowlist 交给拆包和 Runtime；特批与已展开包均不能扩大权限。协议请求由 `platform/ai` 的 `MoonshotToolsClient` 负责，使用当前运行的 AI 配置与密钥，调用 `/v1/tools/search`、`/v1/tools/fetch`，禁止认证重定向；响应上限 2 MiB、请求上限 60 秒，取消传给原生网络请求。外部响应在协议边界验证，正文仅作资料 observation；错误不回显服务端正文、密钥或原始网络异常。

`kimi_mew` 在调用时读取 `moonshot/mew:latest` 的官方函数声明，单一函数自动选择，多函数时由模型按返回的声明指定 `function_name`；`arguments` 必须符合该官方 schema 才提交 fiber。缺少参数时明确返回「尚未执行」及官方声明，交回同一模型循环补充，不猜函数名或参数。只允许该 Formula 的已声明函数，不开放任意 Formula 执行。成功输出与 protected 密文原样回灌，不套用搜索资料前缀，也不自动播放音频；随机结果不声明幂等。

搜索与抓取消耗当前 Moonshot 账号的服务额度，不另存一份密钥。未接入旧 `$web_search` 或云端 memory、Excel 等能力。接口依据：[搜索](https://platform.kimi.com/docs/api/tools-search)、[网页抓取](https://platform.kimi.com/docs/api/tools-fetch)、[Formula 官方工具](https://platform.kimi.com/docs/guide/use-official-tools)。

## 通用联网工具

服务配置入口为「发现 → AI 工具 → 联网搜索」，联网工具包详情也可直达。三个工具默认向所有支持工具调用的聊天 AI 开放，逐 AI 开关与全局默认继续沿用提示词中心的现有权限；配置搜索来源不会扩大调用权限。

- `web_search`：支持内置 Bing RSS、DuckDuckGo HTML，以及用户自配的 Tavily、Brave Search API。省略 `engine` 优先使用用户默认来源，AI 可明确指定其他已启用来源；默认 5 条、最多 10 条。统一返回实际来源、可用来源、标题、链接、相关片段与去重数量。DuckDuckGo、Tavily、Brave 支持时间筛选；Tavily 深度搜索需用户单独允许，默认基础搜索，不启用服务端答案生成或自动升级参数。

  `include_images: true` 仅适用于已启用的 Tavily，默认关闭；默认来源为其他引擎时，模型需显式指定 `engine: "tavily"`，不在传输层自动切换来源。请求同步启用服务端图片描述，原生解析边界将全局与逐网页图片候选合并到 `images`，返回完整图片 `url`、服务端 `description` 与可用的 `sourceUrl`。按完整图片地址去重，保留访问签名和尺寸参数；网页资料和图片候选各自遵守 `limit`。合法空结果返回空数组，错误或损坏响应不能伪装成未找到图片。协议依据：[Tavily Search](https://docs.tavily.com/documentation/api-reference/endpoint/search)。

  图片候选和描述是外部搜索资料，不代表模型已经看过图片，也不保证手机能访问图片站点。AI 选取候选后继续调用现有 `download_image` 入库、`view_image` 看图；搜索不自动下载、不代理图片，不增加第二套存储或视觉读取流程。未请求图片时沿用普通网页搜索结果。
- `web_fetch`：读取公开 HTTPS 网页或文本，保留标题、列表、链接、基本表格与代码块；默认正文 12000 字符、最多 20000 字符。`find` 定位关键词，`start_char` 选择起点；续读使用返回的 `nextStartChar` 和 `documentVersion`，分别传入 `start_char` 和 `document_version`。每次重新读取来源并核对正文指纹，页面变化时明确报错，不把新正文拼接到旧偏移。未找到关键词返回空正文与空匹配。不运行脚本、不借用用户登录态，不解析 PDF 等二进制文件。
- `download_file`：下载公开 HTTPS 文件，最大 50 MiB，保存到 `Download/RavenCat AI/`，返回实际文件名、目录、`content://` URI、类型和大小。所有 AI 共用这个独立目录，不与 `Download/RavenCat/` 的备份产物混放。文件名保留扩展名并添加唯一后缀，不覆盖已有文件，也不打开或执行下载内容。

头像与表情素材使用图片工具包的 `download_image`（归 Media Feature），走同一联网边界但只暂存于应用缓存，再提交到私有 MediaAsset 库，返回媒体 ID；不会显示在相册或公共下载目录。`download_file` 继续用于用户可见的普通文件。

内置来源无需密钥；Bing RSS、DuckDuckGo HTML 都不是承诺稳定的商业 API，验证码、限流、非法响应和网络失败明确返回错误。每次仅请求指定来源，AI 根据资料质量或错误决定改写查询、换来源或继续读原文，不在传输层隐藏轮换、重试或伪造空结果。不同引擎的分数不混排，同标题或跨站转载不按 URL 强行合并，也不能当成多份独立证据。

DuckDuckGo 在中国大陆网络下通常无法直连。开启系统代理后可使用手机配置的 HTTP 代理，或已接管本应用的 VPN/TUN；不要求代理软件使用全局规则。关闭开关时仍使用严格公网 DNS 边界，Fake-IP 会明确报错。开启代理或 VPN 不代表来源一定可用，验证码、限流与真实网络失败仍需分别判断。

## 搜索配置与凭据

Web Tools 独立拥有配置，不复用辅助模型的模型名、温度等资产字段。SQLite 保存来源启用、默认选择、连接方式、深度权限和安全存储引用；API Key 存于 SecureStore，配置页直接回填，测试成功后保留在输入框中，不进入工具参数、模型结果或日志。连接测试始终使用当前输入框中的密钥，输入为空时不请求；测试未修改的密钥不重复发布配置。Tavily、Brave 仅连接固定官方 HTTPS 端点，认证请求禁止重定向。

配置页顶部复用 STT 资产列表的 `ConfiguredModelPicker`，点击弹出选择列表，选择后立即保存生效来源，也可取消选择。候选只包含内置来源和本机凭据可用的自有服务；已保存但缺失凭据的选择明确显示不可用，不静默替换。选择旧配置中曾停用的可用来源时，在同一事务内启用并设为默认，不保留独立的来源启用命令或开关。

选择器下方只放通用 `ToggleField` 系统代理开关，关闭对应直连，打开对应跟随系统代理，说明统一放顶部帮助。下方列表始终展示四个来源，Bing、DuckDuckGo 只展示名称；Tavily、Brave Search 点击展开密钥配置，切换或折叠保留未保存输入，不切换生效来源。选择器、弹窗和列表统一使用主题表面，普通与玻璃主题共用同一流程。正文不重复页面标题和说明。

连接方式同样由 Web Tools 的 SQLite 配置持有，默认直连，随数据库备份恢复；旧库升级保持直连。Feature 装配时将读取配置的 port 提供给 `@platform/web`，搜索、网页读取、公共文件下载和私有图片下载共用该入口，每次请求读取并冻结连接方式，原生句柄创建前后均遵守运行取消。设置不影响模型接口或其他工具的网络实现。

首次成功测试并配置自有服务后自动启用并设为默认；之后新增或替换服务不覆盖用户已有选择。测试会消耗一次基础搜索额度。测试结果以开始时的配置 revision 为提交 fence，迟到结果不能覆盖期间发生的修改；新凭据先写安全存储，SQLite 事务发布引用，失败回收新引用、成功回收旧引用。进程中断可能留下未引用凭据，不会暴露明文或覆盖已有密钥。

完整本地备份按数据库快照引用导出 Tavily、Brave 的 Key，随稳定设置明文归档；恢复时保留原引用写回 SecureStore，不重新测试连接或改变来源选择。只导出被引用的搜索凭据，原本缺失的值显式保存为 `null`；恢复前校验输入格式、搜索命名空间与数据库引用，失败回滚由备份事务的旧稳定设置快照负责。旧包没有导出的 Key 仍需重新填写。

取消默认选择保留已配置密钥，用户可在顶部重新选择，执行时不偷偷降级到另一服务。密钥在展开的配置卡片中修改并测试保存，不提供单独删除入口。恢复后若安全存储中的密钥缺失，配置页允许重新填写并测试，执行时明确报告，不以免费搜索掩盖。

搜索结果在原生解析边界统一去重：忽略片段标识与明确的 `utm_*`、`gclid`、`fbclid`、`msclkid` 参数，保留原始来源链接、业务参数、路径大小写和尾斜杠。同页重复条目保留首次排序并合并不同片段，不建立跨轮全局过滤记录。

## 所有权与链路

Host 唯一工具注册表 → 现有权限与 `open_tool_package` → Agent Runtime 参数校验与执行 → Feature 工具 → `@platform/web` → `modules/web-tools` → observation 回灌同一 Runtime。

Feature 拥有工具用途、参数、服务配置和模型结果文案；application 通过 Repository 与凭据 port 工作，Host 经 composition 出口装配具体实现。原生边界拥有来源协议、结果解析、URL 去重、正文提取、DNS、重定向、响应类型与大小、文件名和公共目录写入。内部调用信任 Runtime 的 schema 契约，不再次检查参数类型或范围。外部网页与搜索内容明确作为资料呈现，不获得指令权限。

实际网络访问只允许 HTTPS，禁止 URL 中的凭据和非公网 IP 字面量；每次重定向重新经过相同边界，最多 5 次。直连时 DNS 校验使用实际连接地址，禁止本机与私网目标。搜索链接只是来源元数据，允许返回 HTTP 来源，但读取或下载仍要求 HTTPS。

跟随系统代理时，每个目标由 Android 系统 `ProxySelector` 选择首选代理或直连，遵守系统的代理排除规则；没有显式代理且本应用未使用 VPN 时，仍使用原有公网 DNS 校验。代理失败不自动切换直连、不重试。代理端点来自用户的系统配置，可以是本机或局域网；代理路由由用户信任的代理解析目标域名并负责其地址边界，不声称本机 DNS 已校验代理实际连接的地址。HTTPS 证书验证、禁止 URL 凭据／非公网 IP 字面量、认证请求禁止重定向继续适用。

系统代理开启、未选用显式 HTTP/SOCKS 代理且 `ConnectivityManager.activeNetwork` 确认为本应用的 VPN 时，DNS 与 socket 绑定到该同一个 `Network`。只允许这个 VPN 的 DNS 返回 `198.18.0.0/15` Fake-IP；公网结果仍正常连接，其他私网、回环、链路本地地址仍被拒绝，URL 中直接填写 Fake-IP 也不会获得例外。VPN 断开时绑定网络的连接失败，不转用底层网络；关闭开关或未使用 VPN 时不允许 Fake-IP。该边界支持真实的 TUN 域名映射，不根据“手机安装了代理软件”或全局 VPN 标志放宽检查。

网络异常在原生 HTTP 边界分类为 DNS、超时、TLS、连接失败或其他读写失败，工具结果保留目标主机、所选连接方式、异常类型和原始原因链；不再合并成笼统的“网络连接失败或超时”。异常详情中的 URL 路径及参数和已知搜索认证值会脱敏，HTTP 拒绝仍保留状态码。取消优先于失败结果，内部异常不伪装为网络故障，不增加重试或降级。

请求句柄同步创建，取消转发到原生网络调用，包含尚未开始的异步请求；文本响应最多 2 MiB、RSS 最多 1 MiB，下载采用流式写入并限制实际字节数。连接超时 15 秒、读超时 20 秒，单次请求上限 60 秒、下载上限 120 秒，关闭传输自动重试。

原生搜索、网页读取、文件及图片下载通过协程在 IO 线程执行阻塞操作，不占用 Expo 共享的默认异步队列；AI 联网期间，配置页读取安全存储中的密钥无需等待网络结束。

下载通过 Android MediaStore 创建新条目，写入期间 `IS_PENDING=1`，写完才发布；失败或取消删除该次条目。发布与取消共享线性化点，已经发布的用户文件不会因随后发生的运行取消而删除。仅写入应用自己创建的下载条目，无需新增存储权限。进程被系统杀死不提供断点续传，未发布条目的到期清理由 MediaStore 负责。

验证：`npm run verify:web-tools` 覆盖工具权限、切换、取消、密钥隔离、配置竞态、数据库升级及配置页交互；原生编译与单测：在 `android/` 运行 `gradlew.bat :web-tools:testDebugUnitTest`，覆盖结果解析、URL 去重、正文结构、定位、续读与页面变化。真实网络探针添加 `-PwebToolsRealNetwork=true`；Tavily、Brave 的账号请求需有效密钥实测。公共目录实际可见性和取消删除需 Android 设备验收，不构建完整 APK。

原生模块接口发生变化后，必须更新并安装包含对应原生代码的安装包；Metro 重载或仅更新 JS 不会替换手机上的原生实现。出现原生调用参数数量不匹配时，先核对安装包与 JS 是否来自同一版本，不能将其判断为密钥无效或搜索服务故障。
