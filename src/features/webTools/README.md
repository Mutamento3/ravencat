# 联网工具包

入口仅为「提示词中心 → 工具调用 → 联网工具包」。三个内置工具默认向所有支持工具调用的聊天 AI 开放，逐 AI 开关与全局默认沿用现有权限，不提供服务配置页或小程序入口。

- `web_search`：调用 Bing 公开 RSS 搜索，返回标题、链接和摘要，默认 5 条、最多 10 条。
- `web_fetch`：读取公开 HTTPS 网页或文本，返回标题、正文、来源链接和截断状态；默认正文 12000 字符、最多 20000 字符。不运行脚本、不借用用户登录态，不解析 PDF 等二进制文件。
- `download_file`：下载公开 HTTPS 文件，最大 50 MiB，保存到 `Download/RavenCat AI/`，返回实际文件名、目录、`content://` URI、类型和大小。所有 AI 共用这个独立目录，不与 `Download/RavenCat/` 的备份产物混放。文件名保留扩展名并添加唯一后缀，不覆盖已有文件，也不打开或执行下载内容。

无需搜索密钥、MCP 或辅助模型配置。Bing RSS 是公开搜索入口，并非有稳定性保证的商业 API；结果质量和可用性由上游决定，验证码、限流、非法响应和网络失败明确返回错误，不切换第二来源或伪造空结果。

## 所有权与链路

Host 唯一工具注册表 → 现有权限与 `open_tool_package` → Agent Runtime 参数校验与执行 → Feature 工具 → `@platform/web` → `modules/web-tools` → observation 回灌同一 Runtime。

Feature 只拥有工具用途、参数和模型结果文案；原生边界拥有 URL、DNS、重定向、响应类型与大小、文件名和公共目录写入。内部调用信任 Runtime 的 schema 契约，不再次检查参数类型或范围。外部网页与搜索内容明确作为资料呈现，不获得指令权限。

实际网络访问只允许 HTTPS，禁止 URL 中的凭据、本机与私网目标；DNS 校验使用实际连接地址，每次重定向重新经过相同边界，最多 5 次。搜索链接只是来源元数据，允许返回 HTTP 来源，但读取或下载仍要求 HTTPS。

请求句柄同步创建，取消转发到原生网络调用，包含尚未开始的异步请求；文本响应最多 2 MiB、RSS 最多 1 MiB，下载采用流式写入并限制实际字节数。连接超时 15 秒、读超时 20 秒，单次请求上限 60 秒、下载上限 120 秒，关闭传输自动重试。

下载通过 Android MediaStore 创建新条目，写入期间 `IS_PENDING=1`，写完才发布；失败或取消删除该次条目。发布与取消共享线性化点，已经发布的用户文件不会因随后发生的运行取消而删除。仅写入应用自己创建的下载条目，无需新增存储权限。进程被系统杀死不提供断点续传，未发布条目的到期清理由 MediaStore 负责。

验证：`node scripts/verify-web-tools.mjs`；原生编译与单测：在 `android/` 运行 `gradlew.bat :web-tools:testDebugUnitTest`；真实网络探针添加 `-PwebToolsRealNetwork=true`。公共目录实际可见性和取消删除需 Android 设备验收，不构建完整 APK。
