# Wallet Presentation

Wallet 的界面层，包含首页、快捷记账、历史日/周/月视图和历史详情。

业务实体与仓储端口位于 `../domain/`，用例位于 `../application/`，具体依赖由
`../composition.ts` 装配。外部模块不要从本目录深度导入，应统一使用：

```ts
import { WalletScreen } from '@features/wallet';
```

本目录只保留界面职责；SQLite 访问和 AI 回复编排不应写入组件。

首页和历史详情的账单均支持长按选择编辑或删除，删除仍需确认。编辑复用
`AddRecordModal`，可修改类型、分类、金额、备注和日期，不改变账单 ID 与创建时间。
历史分类超过五条时可展开全部记录；页面重新获得焦点后刷新账单与统计。

Wallet AI 工具支持新增、查询、编辑、删除账单。查询与新增的模型可见结果包含真实
账单 ID；编辑只更新传入字段，删除或编辑不存在的记录返回失败。金额不明确时应先
询问用户。AI 新增复用账单新增用例，但不安排记账自动回复，避免递归触发聊天。
