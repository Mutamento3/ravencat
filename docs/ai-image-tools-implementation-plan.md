# AI 图片与自主表情工具实施计划

状态：代码、迁移和自动化验证已完成；Android 设备验收待进行。未构建 APK。

## 已确定范围

- 联网图片保存到应用私有持久媒体目录，下载记录持有媒体引用并返回媒体 ID。
- 通用看图支持媒体 ID、用户头像、自己头像与其他 AI 头像；群聊头像和群聊工具开放暂不纳入。
- 原生视觉把真实图片交给下一轮模型；辅助视觉沿用当前角色选择。工具附图不是用户聊天事实。
- AI 只能换自己的头像、维护自己的表情收藏；用户界面和用户命令只访问用户库。图片读取开放。
- 用户与各 AI 的收藏复用同一媒体系统；收藏语义和向量分别归属收藏记录。
- AI 只导入静态表情，复用全局表情识别模型，然后尝试一次向量化。失败保留状态与原因，不自动重试。
- AI 可显式重试识别或向量化、修正语义、删除自己的收藏。编辑语义后旧向量失效。
- 缺向量的已标注表情仍可词面检索和发送，工具结果提供状态提醒；不增加用户维护入口。
- 使用现有新消息打断旧回合的链路。模型请求随工具取消，持久 claim / revision 阻止晚到结果提交；不新增停止按钮。

## 实施顺序

1. 扩展表情归属、私有下载引用与 AI 处理状态，迁移保留已有用户收藏和向量。
2. 接入私有图片下载与媒体生命周期、备份和角色删除回收。
3. 在统一 Agent observation / history 中支持工具附图，接入通用看图和自身头像命令。
4. 实现 AI 收藏及显式维护，复用识别与 embedding 端口；用户后台队列排除 AI 收藏。
5. 注册工具、补充图片 ID 与向量状态提示，更新当前架构说明。

## 已实现入口

- `download_image`：私有下载，返回媒体 ID。
- `view_image`：通用看图及头像查询，原生 / 辅助视觉沿用角色选择。
- `change_own_avatar`：仅修改自己的头像，事务内检查回合资格与头像 CAS。
- `add_own_sticker`：收藏静态图，识别和向量化各自动尝试一次。
- `maintain_own_sticker`：查询、显式识别 / 向量化、修正语义、删除自己的收藏。

数据库版本升级为 120，保留原用户收藏、标注和向量；AI 收藏及下载引用纳入同一媒体回收与备份范围。没有新增群聊工具、停止按钮或用户维护 AI 库的页面。
