# 对话展示信息自动保存

## 入口与范围

单聊「更多功能 → 对话设置」修改助手名称、头像、AI 人设、上下文可见条数、多气泡回复与 Token 用量显示开关。「更多」将模型设置与对话设置相邻排列，与协议空间、聊天摘要等内容管理入口分组。
聊天背景与通话背景继续由原有组件及命令独立提交。群聊信息保持现有流程；管理员配置遵循 [模型设置自动保存](model-settings-autosave.md)。

- 名称与人设停止输入 1 秒后保存，失焦提前提交；正常保存不提示成功、不自动返回。
- 名称下方提供 AI 昵称，沿用相同自动保存节奏；去除首尾空白后最多 20 个 Unicode 字符、只允许单行，空值清除备注。仅用户可写，AI 只能读取自身昵称。用户界面优先显示昵称，公开名称字段及模型成员目录继续使用原名。
- 四项上下文条数同样停输 1 秒或失焦提交，必须为正整数；多气泡开关立即提交。主题不支持分段时仍保留用户选择。
- Token 用量开关立即保存，默认开启，只影响当前 AI 的单聊展示，不停止用量记录。paper-note 与 moon-kimi 主题固定关闭并禁用该开关，保留原选择以便切回支持主题后恢复；消息提示仍由主题能力限制最终展示。
- 空名称显示字段错误并保留草稿；写入失败保留草稿，提供重试和恢复已保存值。
- 单聊头像选择或恢复默认后立即提交；失败保留头像草稿并在头像区域显示错误。
- 名称、人设和头像按字段独立提交，空名称不影响人设或头像保存。人设可留空清除，正文保留输入排版。助手头像命令不接收名称或人设。
- 单聊返回先等待头像操作，并提交对话设置修改；未保存的无效输入或头像草稿会阻止返回。
- 固定消息起点入口复用同一离开流程，保存成功后由宿主 Expo Router 返回消息列表。固定期间保留近期条数原值并暂时禁用“单聊·主”；起点与摘要开关按当前 AI 的 canonical 单聊独立保存，详见[摘要与固定范围](chat-summary.md)。
- 名称草稿与数据库确认分开，旧确认及头像更新不覆盖用户的新名称输入。

## 所有权

Chat 页面负责交互节奏、输入校验与离开行为。通用草稿确认使用 shared/ui 的 AutoSaveDraftEditor；字段解析留在 Feature。
助手资料由 Assistants 命令与 Repository 更新。
上下文、气泡与 Token 用量展示设置由 updateAIAssistantSettings 提交到助手字段；显示选择保存于 ai_assistants.show_token_usage，不参与模型调用。模型页不编辑或重置这些对话字段。
名称只提交 name，人设只提交 systemPrompt，头像只提交头像引用。提交回调只回填本次更新的助手字段，并使用最新页面状态合并。
昵称只提交 nickname；当前值和修改历史由助手 Repository 同事务维护，相同值不新增历史。修改提醒在单聊下一次成功最终回复后确认，不在组装提示词或请求失败时消耗；当前昵称和称呼历史持续作为该 AI 自身的动态上下文提供。
人设仍保存于 ai_assistants.system_prompt，由 Assistants 命令经 databaseCoordinator 提交；提示词中心与后续提示词组装直接读取同一数据库字段，不复制第二份人设。提示词中心的人设详情仅展示，重新获得焦点时读取最新正文。
头像文件草稿继续由 usePersistentAvatarDraft 管理，媒体引用创建及 CAS 保留原来的事务边界。

## 验证

`node --no-warnings scripts/verify-conversation-settings-autosave.mjs` 验证单聊名称、人设与上下文防抖、多气泡立即保存、无效条数拦截、清空人设、写入失败保留草稿、空名称与头像独立更新、头像错误重试及恢复、返回等待和恢复默认头像。
`node --no-warnings scripts/verify-prompt-overview.mjs` 验证人设只读展示及重新获得焦点后的数据库同步。
模型自动保存回归确认迁移到 shared/ui 后的行为保持不变；助手 Repository 验证头像提交不覆盖名称或模型配置。
不构建 APK，原生相册与真实键盘交互需要真机确认。
