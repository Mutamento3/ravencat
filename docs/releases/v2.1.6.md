# RavenCat v2.1.6

本次更新通话记录、聊天流式展示、群聊管理与语音服务，并修复后台摘要装配、工具执行结果等问题。本次以常规发行版发布，不再标记为 Pre-release；项目仍由个人持续维护。

## 新增与改进

- 新增可回放的通话记录，可查看通话详情；支持按 AI 选择是否保存通话中 AI 获取的截图，默认关闭，保存的截图可查看和单独删除。
- 支持按 AI 选择流式回复方式，并支持多个气泡在生成过程中逐步显示；行动步骤和 Token 显示也可按 AI 配置。
- 完善群聊成员管理、工具包与退出记忆，改善群聊语音队列滚动和部分回复状态展示。
- 接入 Fish Audio 原生语音合成，补充表达标签和使用示例，保留语音服务返回的具体错误原因。
- 固定消息上下文起点作为常规功能提供，移除设置页和当前 README 中的实验性标记。

## 修复

- 修复聊天消息触摸偶发失效、内容增长时提前结束贴底，以及首页群聊最新消息预览漏刷。
- 修复通话主动挂断标记位置影响回复、拨号错误展示和错误原因丢失；区分模型回复、语音合成与语音识别失败。
- 持久化摘要队列，取消启动时全量扫描，补齐后台运行时的摘要与搜索依赖装配。
- 修复协议工具虚假报告成功和模型无法看到协议 ID 的问题，改善工具权限说明。
- 修复通话截图设置的数据库升级问题，并改善语音输入的键盘、焦点和滚动交互。

## 固定消息上下文起点

在单聊消息列表中长按消息，选择「固定」，即可将该条消息设为上下文起点；在对话设置中可查看、重新设置或取消固定。

固定后，起点至最新消息的全部原文进入上下文，近期条数暂不生效，自动生成摘要暂停。对话增长会增加 Token 消耗，可能超出模型的上下文额度。取消固定后恢复近期条数，自动生成摘要需手动重新开启，并沿原来的摘要进度继续。

## 使用说明

- 支持 Android 13 及以上；本次包含原生模块变更，需要安装新版 APK 后生效。
- 下载 `RavenCat-2.1.6.apk` 安装，或在支持更新的旧版应用中检查更新。沿用原包名与发布签名，可覆盖原预览版；白底 `.dev` 开发版仍是独立应用。
- 更新前建议导出本地备份。全量备份不加密，包含服务凭据，请私下保管。
- 通话记录不会补录旧电话或已经清理的音频；关闭截图保存不会删除此前保存的截图。
- 项目由个人持续维护。后台执行、覆盖安装、应用内更新与跨设备恢复仍需真实设备验证；反馈时请附设备、应用版本与复现步骤，并移除私人内容。
