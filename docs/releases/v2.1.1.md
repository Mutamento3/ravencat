# RavenCat v2.1.1 实验性预览版

本次优先发布近期修复，并包含一批新功能。版本为 **2.1.1**，仍以 **Pre-release（预发布）** 发布，整包属于实验性预览版本，尚不能承诺所有手机、模型服务与后台场景都稳定。

## 本次修复

- 删除聊天消息时保留已经加载的历史窗口与分页位置。
- 修复群聊提及角色列表无法滚动和候选项被截断的问题，改善玻璃主题召唤队列面板。
- 摘要输出改为纯正文，减少模型未按 JSON 格式返回造成的失败。
- 调整语音标签处理，并修正群聊工具说明与函数参数的冲突。
- 思维链支持 Android 原生长按选择、跨 Markdown 段落连续选择复制。
- 修复记忆星空双指缩放松手时的位置跳动，改善星球与记忆星点展示。
- 统一表单输入与键盘避让，移除群聊中不支持的通话入口。
- 一起听退出使用独立事件记录，并按双方显示名称展示提示。

## 新增与调整

- 群聊两级摘要、主客上下文额度和相关群工具。
- 用户私有 AI 昵称、称呼历史与修改提醒；昵称备注与模型上下文的边界独立处理。
- 通用辅助模型管理与独立配置复制。
- 一起听根据播放进度注入当前一句歌词。
- 记忆星空采用有来源记录的真实天体影像，记忆星点环绕对应行星。

新功能仍需真实模型和真机体验反馈；本次修复不代表已经完成所有新功能的设备验收。

## 固定消息上下文起点仍为实验性功能

固定后，起点至最新消息的全部原文进入上下文，自动摘要暂停；对话持续增长可能增加 Token 消耗并超出模型上下文额度。取消固定后，自动摘要需手动重新开启。

## 安装与使用

- 支持 Android 13 及以上，下载 `RavenCat-2.1.1.apk` 安装。
- 本次版本高于 `2.1.0-preview.1` 和 `2.0.2`，已具备更新功能的旧版可检查本次更新；也可手动下载安装包。
- 包名沿用 `com.skylucky.kimiphone`，使用原发布签名；无需先卸载旧预览版。白底 `.dev` 开发版仍是独立应用。
- 更新前建议导出备份；全量备份不加密，并包含服务凭据，请私下保管。
- 应用不附带模型服务或 API Key，需要配置自己的服务。
- 反馈请附手机型号、Android 版本、应用版本和复现步骤，移除凭据与私人内容。

第三方许可、素材来源与署名随 `RavenCat-2.1.1-third-party-notices.zip` 提供，附件校验值见 `SHA256SUMS.txt`。原创内容采用 MIT，第三方素材、组件与服务遵循各自条款。

本次构建与自动化检查不能替代真机验收；应用内下载、覆盖安装、新功能表现与后台行为仍需在设备上确认。
