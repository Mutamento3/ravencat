# RavenCat v2.1.2 实验性预览版

本次集中发布聊天显示、滚动与悬浮交互的近期修复，仍标记为 **Pre-release（实验性预览版）**。

## 本次修复

- 思维链长按选择文字时，隔离原生选择焦点引发的自动滚动；折叠前释放选区，减少折叠空白与位置跳动。
- 保持消息列表的滚动容器稳定，避免更新时重新创建容器。
- 修复分页定位期间停下滚动后，末次位置没有被消费、列表出现空白的问题。
- 扩大行动步骤的点击区域，修复快速连点展开与收起的竞态。
- 改善聊天键盘与表情、功能面板之间的切换。
- 统一主理 AI 任命提醒，补全撤销后的后果说明。
- 调整聊天摘要与语音工具在提示词中心的展示分类。
- 移除无效伴随恢复入口；悬浮聊天没有可用目标时，正常展示提示并结束任务。

## 实验性功能

固定消息上下文起点仍属于实验性功能：固定后，起点至最新消息的全部原文进入上下文，自动摘要暂停；对话增长可能增加 Token 消耗并超出模型额度。取消固定后，自动摘要需手动重新开启。

预览版本仍需要不同设备、模型与后台场景的反馈；本次修复不代表全部新功能已完成真机验收。

## 安装与使用

- 支持 Android 13 及以上，下载 `RavenCat-2.1.2.apk`，或在旧版应用中检查更新。
- 沿用原包名与发布签名，可以覆盖原预览版，无需先卸载。白底 `.dev` 开发版仍是独立应用。
- 本次新增原生文字选择适配，需要安装新版 APK 后生效。
- 建议更新前导出本地备份。全量备份不加密，包含服务凭据，请私下保管。
- 反馈时请附手机型号、Android 版本、应用版本与复现步骤，移除凭据和私人内容。
