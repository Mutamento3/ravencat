# RavenCat v2.1.0-preview.1 预览版

本版本以 Preview / Pre-release 发布，用于体验新功能与反馈问题，仍需更多真机验证。

## 实验性功能：固定消息上下文起点

在单聊消息列表中长按消息，选择「固定」，可将该条消息设为上下文起点；对话设置中可查看、重新设置或取消固定。

- 仅作用于当前 AI 的单聊，起点至最新消息的全部原文进入上下文，近期条数设置暂时不生效。
- 固定后暂停两级摘要的自动生成，已有摘要是否注入仍由摘要页面独立控制。
- 对话持续增长会增加输入 Token 用量、请求成本与处理时间，也可能超出模型的上下文额度。
- 取消固定、删除起点或清空消息后恢复近期窗口；自动生成摘要需要手动重新开启。

该功能目前属于实验性功能，后续可能调整交互与行为。使用前请了解所选模型的上下文额度。

## 本次更新

- 聊天摘要增加两级归纳、独立生成与注入开关、专用设置页、持久任务与失败诊断；真正失败后最多自动重试一次，支持手动重试。
- 记忆按关联组管理多个触发词与多条记忆，AI 可查询聊天摘要。
- 增加独立消息收藏与分类；改善图片引用的媒体保留与缩略图展示。
- 显示模型返回的输入、输出与缓存 Token 用量，单聊支持独立显示开关。
- 增加 AI 私有图片、主动看图、自主头像与表情库维护，以及按需授权的定位工具。
- 修复通知返回聊天、Android 页面重建后的相册与相机入口、长截图视觉输入与键盘避让时的列表跟随。
- 改善玻璃主题、摘要与记忆编辑界面、羽库分类录入、按钮对比度和列表滚动。
- 修复执行生命周期及消息删除、摘要任务等持久化操作的并发与恢复问题。

## 安装与反馈

- 支持 Android 13 及以上；下载 `RavenCat-2.1.0-preview.1.apk` 安装。
- 预览包使用 `com.skylucky.kimiphone` 与原发布签名；Android 系统安装确认通过后可覆盖更新。白底开发版 `.dev` 是独立应用。
- 更新前建议导出本地备份。全量备份不加密，包含服务凭据，请私下保管。
- 应用不附带模型服务或 API Key，需要配置自己的服务。
- 反馈时请附手机型号、Android 版本、应用版本与复现步骤，并移除凭据和私人内容。

附件 `RavenCat-2.1.0-preview.1-third-party-notices.zip` 提供项目许可、素材来源与第三方声明；`SHA256SUMS.txt` 提供附件校验值。原创内容采用 MIT，第三方组件与服务遵循各自许可和条款。

自动化验证与构建核对不能替代真机验收；本版的完整应用内下载、覆盖安装与新功能体验仍需在发布后验证。
