# RavenCat v2.1.7

本次更新聊天记录搜索、图片发送、提示词与摘要管理，并改进通话、联网搜索和工具执行。继续以常规发行版发布；伴随模式与小红书文字笔记工具仍属于实验性功能。

## 新增与改进

- 单聊和群聊新增聊天记录关键词搜索，可从结果定位原消息；AI 工具支持搜索聊天原文和按消息 ID 读取附近上下文。
- 聊天支持一次选择最多九张图片发送；新增 AI 图片消息发送工具，完善搜索图片、下载、查看与发送之间的衔接。
- 保存聊天和通话文字草稿，并在会话列表展示聊天草稿摘要。
- 重整提示词中心，支持将当前 AI 的配置应用到全局、清空覆盖配置，并可编辑一级、二级摘要提示词；调整摘要默认正文，侧重保留重要记忆。
- 支持按 AI 自定义来电铃声和拨出等待音；通话语音打断改用持续人声检测，减少噪声造成的误打断。
- 联网搜索支持选择来源和系统代理，完善错误诊断；使用 Tavily 时可按需检索图片候选。
- 手机应用工具包新增独立总开关；新增主理 AI 按需读取剪贴板的工具。小红书文字笔记改为逐步观察和操作，发布前核对内容并使用一次性凭据。
- AI 请求诊断改进大段正文阅读，并支持分别复制请求与响应正文。

## 修复

- 修复流式与 Agent 正文已到达后，通知、会话列表预览和未读数更新不同步的问题。
- 修复消息收藏状态、再次点击取消收藏、历史表情包加载，以及清除聊天记录后的分页与展示状态。
- 改善前台来电接听界面、通话小窗恢复和权限请求交接；修复音频建立失败误记为已通话、自定义拨号音被错误音量通道静音等问题。
- 保留模型、网络和工具调用失败的具体原因，修复部分业务失败被工具错误报告为成功的问题。
- 修复日程与聊天执行协调、过期日程收口和日程时间上下文，并补充执行阶段诊断。
- 修复本地备份遗漏联网搜索密钥，以及模型设置中思维链开关的语义。

## 实验性功能

伴随模式仍需不同设备和后台场景的验证。小红书文字笔记工具尚不稳定，只支持部分机型与页面，可能受应用更新、键盘和系统弹窗影响；请先小范围测试，并自行核对发布结果。工具返回发布结果不明时，不应自动重发。

## 安装与使用

- 支持 Android 13 及以上；本次包含原生模块与依赖变更，需要安装新版 APK 后生效。
- 下载 `RavenCat-2.1.7.apk` 安装，或在支持更新的旧版应用中检查更新。沿用原包名与发布签名，可覆盖原公开版；白底 `.dev` 开发版仍是独立应用。
- 更新前建议导出本地备份。全量备份不加密，包含服务凭据，请私下保管。
- 固定消息上下文起点会把起点至最新消息的全部原文纳入上下文，并暂停自动摘要；对话增长可能增加 Token 消耗或超出模型额度。取消固定后，自动摘要需手动重新开启。
- 新版本识别仍依赖 GitHub；Gitee 国内下载附件由维护者单独上传，可能稍晚就绪。
