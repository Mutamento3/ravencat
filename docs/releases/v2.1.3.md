# RavenCat v2.1.3 实验性预览版

本次集中更新聊天展示、后台执行、通话和工具能力，继续以 **Pre-release（实验性预览版）** 发布。

## 修复与改进

- 改善聊天气泡交接、历史分页、自动贴底、键盘切换与长消息展示，减少消息闪烁、位置跳动和输入交接提示。
- 持久保存已经交付的回复与行动步骤；中断后保留已发生的工具结果，改善运行阶段、Token 与缓存统计的展示。
- 调整普通聊天后台任务的执行生命周期、启动回执和超时收口，修复 Headless 任务结束后的资源滞留。
- 修复通知打开聊天后的返回栈，以及通话结束重复返回、接听来源与界面重建后的返回位置；通话复用 Agent 工具能力。
- 新增多来源联网搜索及配置管理，支持由 AI 按授权调整应用设置与图片自动裁剪。
- 统一提示词装配、工具包展开与收起、模型思考协议和 ElevenLabs Audio Tags 处理。
- 改善主理 AI 冷静期与身份变更交互、昵称历史、时刻评论与未读社交上下文，以及记忆星空的玻璃面板效果。
- 区分开发环境与公开 APK 的更新入口。

## 实验性功能

固定消息上下文起点仍属于实验性功能：固定后，起点至最新消息的全部原文进入上下文，自动摘要暂停；对话增长可能增加 Token 消耗并超出模型额度。取消固定后，自动摘要需手动重新开启。

本版本仍需不同设备、模型与真实后台场景的反馈；新增能力与后台执行调整不代表已经完成全部真机验收。

## 安装与使用

- 支持 Android 13 及以上，下载 `RavenCat-2.1.3.apk`，或在旧版应用中检查更新。
- 沿用原包名与发布签名，可以覆盖原预览版，无需先卸载；白底 `.dev` 开发版仍是独立应用。
- 本次含原生模块变更，需要安装新版 APK 后生效。
- 建议更新前导出本地备份。全量备份不加密，包含服务凭据，请私下保管。
- 反馈时请附手机型号、Android 版本、应用版本与复现步骤，移除凭据和私人内容。
